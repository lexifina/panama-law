# Artículo 15
Al aplicarse la ley penal a un hecho, este no podrá ser considerado más de una vez para la imposición de otra sanción. En caso de concurso ideal o real del delito, se aplicarán las normas correspondientes establecidas en este Código.
Cuando varias leyes penales o disposiciones de este Código sancionen el mismo hecho, la disposición especial prevalecerá sobre la general.
Esta garantía también rige para los casos juzgados en el extranjero.
